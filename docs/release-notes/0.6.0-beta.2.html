What's New in UseMac 0.6.0 Beta 2

  • The Chrome tab UseMac works in keeps its real width and no longer flickers while you look at it.
  • The preview never shows another app (such as your own screen) when an agent's activity names no app, and each Chrome tab appears once in the filmstrip.
  • The Resume button in the Stopped pill fits on one line.
  • The Chrome extension reports its real version.

After updating, reload the UseMac Browser Bridge in chrome://extensions so Chrome picks up the new extension.

This is a beta. Please report problems at github.com/diegosquid/usemac/issues.
