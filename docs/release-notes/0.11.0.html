What's New in UseMac 0.11.0

  • Connect agents from Settings. Quick Setup configures UseMac for Claude Code, Claude Desktop, Cursor, Codex, and Antigravity, with a backup of existing settings.
  • Set rules per app or site. Choose Allow, Ask, Read-only, or Block. Your existing rules are kept.
  • Drag and save. Agents can drag in Chrome and native apps, and save to a specified path in a native Save dialog.
  • Handle Chrome dialogs. Alerts, confirmations, prompts, and leave-page dialogs no longer leave an action waiting indefinitely.
  • Wait for a busy tab or window. Agents can queue for a target that's in use.

For a Chrome extension loaded from the app bundle, use Settings → Chrome Extension → Reload after updating. If you loaded the extension from another folder, updating the app does not update that copy.
