What's New in UseMac 0.9.0 Beta 1

  • Agents can do more in one turn: open a page, dismiss common overlays, fill a form and check the result together. Optional steps and bounded scrolling help workflows handle pages that change.
  • Agents can search and use native app menus in the background, read several pages in parallel, and save reusable workflows.
  • Smaller observations and faster local reads: compact page and app snapshots, change-only screenshots, event-driven waits and a smaller MCP tool set reduce repeated work.
  • Vision is now built-in Apple Vision OCR only, with no Python worker or model download. The optional MLX model and its install command have been removed.
  • Agents can read captured XHR/Fetch JSON directly. Single-page app navigation no longer loses responses from the current document.
  • More reliable Chrome downloads: agents can list recent downloads without selecting a tab. Finishing a task keeps a tab open while its download runs, including downloads opened in a new tab, without adding an extra preview card.

After updating, reload the UseMac Browser Bridge from Settings → Chrome Extension. If your extension is loaded from another folder, load the bundled copy from /Applications/UseMac.app/Contents/Resources/chrome-extension to receive app updates.

This is a beta and is not notarized yet. Please report problems at github.com/diegosquid/usemac/issues, or ask your agent to prepare a report.
