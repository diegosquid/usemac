What's New in UseMac 0.6.0 Beta 3

  • Ask mode: uploads, page scripts and ⌘/⌃ shortcuts wait for your OK in the live preview.
  • App and site rules in Settings → General keep agents away from the apps and sites you choose. Password managers are blocked by default.
  • Several agents can work at once: each task keeps its own Chrome tabs and windows, and the preview names the agent on each card.
  • The execution mode picker in Settings → Safety is readable, the Setup guide offers the same modes, and the menu bar shows the mode whenever it isn't Autonomous. Agents blocked by the mode are told which one, so they can ask you.
  • Settings → History keeps 30 days on disk, folds repeated entries into one row and marks actions apart from observations.
  • Report a problem from your agent: UseMac prepares a report without your personal data, and you review it before anything goes to GitHub.
  • While an agent works in a Chrome tab you're looking at, the tab shows a border and a Stop button.
  • Settings → Chrome Extension shows each profile's extension version and reloads it for you.
  • A lighter app icon shadow, and many fixes to scrolling, file pickers, tab groups and the live preview.

After updating, reload the UseMac Browser Bridge once in chrome://extensions. From then on, Settings → Chrome Extension can reload it for you.

This is a beta. Please report problems at github.com/diegosquid/usemac/issues, or ask your agent to prepare a report.
