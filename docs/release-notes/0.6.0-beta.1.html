What's New in UseMac 0.6.0 Beta 1

  • Agents work more reliably in the background: stable element ids, steps that find elements by what they are, background scrolling, and file pickers driven without taking focus.
  • Every step now says whether it changed anything, instead of a silent "ok".
  • Real keyboard and mouse input only goes to the app in front, so it can never land in the app you are using.
  • New filmstrip preview: the active tab large, the others as live thumbnails, with a clear cue when another one comes forward.
  • The preview never shows your own Chrome tabs, and Chrome tabs UseMac opened are closed when the task finishes.
  • Chrome Web Store and chrome:// pages are handled with a native fallback.

This is a beta. Please report problems at github.com/diegosquid/usemac/issues.
