What's New in UseMac 0.10.0

  • Work in the background. Agents can use native app menus, open and read several Chrome pages, and save repeatable workflows. Apple Vision OCR runs on your Mac without a separate model download.
  • Keep tasks separate. Each task keeps its own window selection and tabs. History groups actions by session, and the live preview shows who is working where and centers wide pages without resizing the tab.
  • Stay in control. Site rules apply even when agents use native Accessibility in Chrome. Typing or clicking in an agent-controlled page pauses it there, and visible windows show a border when an agent uses the native fallback on a restricted page.
  • More reliable clicks and downloads. Covered controls aren't clicked, and agents are told when a link click produces no observable result. Downloads keep their tab open until the transfer ends; finishing a task no longer leaves another saved UseMac tab group.
  • Better native file handling. When an app comes forward after a background file selection, UseMac restores the previous focus. The Go to Folder fallback waits for the right field and button before continuing.

After updating, reload the UseMac Browser Bridge from Settings → Chrome Extension. If you loaded the extension from another folder, switch to the bundled copy at /Applications/UseMac.app/Contents/Resources/chrome-extension so future updates can reach it.

Some restricted Chrome pages still need a visible window or a brief foreground step. See the full changelog or report a problem.
