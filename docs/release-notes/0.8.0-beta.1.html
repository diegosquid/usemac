What's New in UseMac 0.8.0 Beta 1

  • The on-device vision model is optional: most tasks don't need it, so Apple Vision OCR reads the screen until you install a model and turn it on. A model you turn on loads the first time a task needs it, unloads after 5 idle minutes, and one copy is shared by every agent.
  • Element and full-page screenshots no longer make Chrome enlarge the page: it scrolls while it is captured and goes back to where it was. Full pages can be up to 16384 px tall.
  • UseMac notices when its safety settings are changed outside it, including the app and site rules and Record typed text. It then starts Paused with safe defaults and tells you, and only you resume.
  • The first launch of this version turns Debug capture and Record typed text off. Turn them on again in Settings if you use them.

After updating, reload the UseMac Browser Bridge from Settings → Chrome Extension.

This is a beta. Please report problems at github.com/diegosquid/usemac/issues, or ask your agent to prepare a report.
