# Code of Conduct

UseMac follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

It applies in the repository's issues, pull requests and discussions, and anywhere someone represents the
project.

## Reporting

Report unacceptable behavior to the maintainer at <hello@usemac.app>. Reports are read only by the maintainer and
kept private. The maintainer decides what happens, following the Contributor Covenant's enforcement guidelines.
