Download for Mac Chrome Extension

After you download

  1. Drag UseMac to Applications and open it. If macOS says it can't verify UseMac, open System Settings → Privacy & Security and click Open Anyway.
  2. Allow Accessibility and Screen Recording when macOS asks.
  3. Add the Chrome extension: open chrome://extensions, turn on Developer mode, click Load unpacked, press ⌘⇧G and paste /Applications/UseMac.app/Contents/Resources/chrome-extension. Then paste the pairing key from UseMac → Settings → General → Chrome Extension.
  4. Paste the setup prompt into your agent.
