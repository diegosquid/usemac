Local-First Privacy Architecture

Privacy Policy

Effective Date: November 25, 2026 · Applies to UseMac macOS App & UseMac Browser Bridge Chrome Extension

In short: UseMac and the UseMac Browser Bridge run on your Mac. We operate no servers that receive your screen contents, browsing data or files, and the app has no analytics or telemetry. What your AI agent sees is sent to the AI service you chose to connect, under that service's terms.

1. How data flows

The UseMac Browser Bridge Chrome extension talks only to the UseMac app running on the same Mac over ws://127.0.0.1:49222. Both ends authenticate each other using a local pairing key stored on your Mac. Your agent communicates with the UseMac app locally over a same-user Unix domain socket or MCP stdio.

When you connect an AI client (such as Claude Code, Cursor, Codex or Antigravity), the screen contents, page text, screenshots and file names that the agent requests are returned to that client. The client typically sends them to its AI provider. UseMac does not control how that provider handles them.

2. Chrome extension permissions

  • tabs — Lists open tab titles/URLs and routes actions to the exact background tab you or your agent target without stealing window focus.
  • tabGroups — Automatically organizes agent-controlled tabs into a clean UseMac Chrome Tab Group so you can always see which tabs are on autopilot and collapse or close them in one click.
  • debugger — Uses Chrome DevTools Protocol (CDP) locally to read interactive DOM trees, dispatch background clicks/typing/uploads, and stream ephemeral JPEG preview frames to the UseMac corner HUD.
  • storage — Saves the profile label you type and the pairing key, inside Chrome's local storage on your Mac.
  • alarms — Keeps the local WebSocket bridge responsive when Chrome puts idle Manifest V3 service workers to sleep.
  • downloads — Detects newly downloaded files triggered by an explicit agent click (e.g., exporting a CSV report) so the local file path can be returned directly to your agent.

The extension does not read your Google account e-mail and does not send window titles or browsing history to the UseMac app unless an agent you connected asks to list or read a tab.

3. What UseMac stores on your Mac

  • App preferences: Local settings such as execution mode, HUD corner, and local vision preferences.
  • Pairing key: The local bridge pairing key used to authenticate the Chrome extension to the UseMac app.
  • Temporary screenshots: Screenshots captured for observation, visual checks, or agents are stored in a private folder inside your user temporary directory and deleted after 30 minutes.
  • Action history: Kept in memory only and cleared when you quit the app.

4. On-device vision and optional downloads

Apple Vision OCR runs natively on your Mac with no network requests. If you optionally install Local Vision inside UseMac Settings, UseMac downloads a Python runtime and open-source packages (via uv, from PyPI) along with the weights for the model preset you selected from Hugging Face. All inference runs locally on your Mac. Those download services see your IP address, like any download.

5. Safety controls

UseMac enforces local guardrails on your Mac: uploadFile blocks sensitive directories and secret files (including ~/.ssh, ~/.aws, ~/.gnupg, Keychains, .env files, browser and password-manager data in ~/Library, shell histories, and .pem, .pfx, .p8, .kdbx, .ovpn, .jks, .keystore, and .tfstate files). Five execution modes (Autonomous, Ask, Block sensitive, Read-only, and Paused) let you control what agents may do, and the global Kill Switch (⇧⌘⎋) immediately blocks all automation including reads and cancels any in-progress Chrome batch.

6. Automatic updates

When automatic updates are enabled, UseMac periodically checks our static Sparkle 2 appcast XML feed to see if a newer signed version is available. Standard HTTP server logs may temporarily record an IP address and macOS version header for bandwidth and security protection, with no personal identifiers or usage analytics attached.

7. This website

This website is static: fonts are self-hosted, and there are no analytics, cookies, or third-party scripts. Our hosting provider may record your IP address in standard server logs.

8. Limited Use disclosure (Chrome Web Store)

The UseMac Browser Bridge's use of information received from Google Chrome APIs adheres strictly to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data accessed in your browser is used exclusively to execute your direct local automation commands and render your local live preview HUD.
